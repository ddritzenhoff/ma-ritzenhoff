\section{List of Acronyms} % titlecase
% titlecase should be either consistently used or consistently not be used.
% mixing titlecase with non-titlecase should be avoided.
\label{sec:acronym}

\begin{acronym}[PCMCIA] % Put the longest acronym in this list into the []
    \acro{0-RTT}{0 Round Trip Time\acroextra{, a feature in TLS 1.3 and QUIC that allows a client to send application data in its very first message to a server when resuming a connection, thus eliminating an entire round trip of latency from the connection establishment process.}}
    \acro{BC}{Boundary Clock\acroextra{, a device that acts as both a slave to an upstream master clock, synchronizing its own time, and then as a master to downstream slave clocks, distributing that synchronized time to other network segments.}}
    \acro{BMCA}{Best Master Clock Algorithm\acroextra{, a distributed selection process where clocks exchange "Announce" messages containing their properties to determine the highest-quality clock to serve as the grandmaster for the entire network.}}
    \acro{BPF}{Berkeley Packet Filter\acroextra{, in-kernel virtual machine that allows sandboxed bytecode to be executed at various hook points.}}
    \acro{CDF}{Cumulative Distribution Function\acroextra{, describes the probability that some random variable $X$ will have a value less than or equal to $x$.}}
    \acro{cBPF}{classic Berkeley Packet Filter\acroextra{, a minimalistic, in-kernel bytecode language and virtual machine primarily used for network packet inspection and filtering.}}
    \acro{CI}{Continuous Integration\acroextra{, an automated validation of code merges through builds and tests.}}
    \acro{CID}{Connection ID\acroextra{, a chosen identifier used by endpoints to identify a QUIC connection, enabling it to persist and be routed correctly even if the underlying IP address or port changes}}
    \acro{CPU}{Central Processing Unit\acroextra{, the "brain" of the computer, where most programs are run.}}
    \acro{DDoS}{Distributed Denial of Service\acroextra{, a malicious attempt to disrupt the normal traffic of a targeted service by flooding it with internet traffic from multiple sources.}}
    \acro{DMA}{Direct Memory Access\acroextra{, a feature that allows hardware components to directly access system memory for reading and writing data without requiring the CPU's intervention.}}
    \acro{DPDK}{Data Plane Development Kit\acroextra{, a collection of open-source libraries and drivers that enable high-performance, kernel-bypass packet processing in userspace.}}
    \acro{DuT}{Device under Test\acroextra{, a device that is investigated during experiments}}%
    \acro{eBPF}{extended Berkeley Packet Filter\acroextra{, an extended, in-kernel bytecode language and virtual machine, which expands on cBPF's capabilities to allow for programmable, event-driven execution across the kernel's subsystems.}}
    \acro{GCC}{GNU Compiler Collection\acroextra{, a compiler system for various programming languages like C and C++.}}
    \acro{GMC}{Grandmaster Clock\acroextra{, an authoritative time source for a Precision Time Protocol (PTP) network.}}
    \acro{GPS}{Global Positioning System\acroextra{, a satellite-based navigation system that provides users with accurate positioning, navigation, and timing information anywhere on Earth.}}
    \acro{gPTP}{Generalized Precision Time Protocol\acroextra{, an adaptation of the Precision Time Protocol specifically designed to provide highly accurate time synchronization for time-sensitive applications within Ethernet networks.}}
    \acro{GRO}{Generic Receive Offload\acroextra{, a software technique that aggregates multiple incoming small packets belonging to the same flow into a single, larger packet within the NIC driver, which reduces the number of packets the CPU has to process and improves receive throughput.}}
    \acro{GSO}{Generic Segmentation Offload\acroextra{, a software technique that splits chunks of data belonging to the same flow into smaller MTU-sized packets, typically at the driver level, which improves sending throughput.}}
    \acro{HoL}{Head of Line}
    \acro{HTTP/3}{Hypertext Transfer Protocol 3\acroextra{, the latest version of the Hypertext Transfer Protocol, which leverages QUIC over UDP to eliminate head-of-line blocking.}}
    \acro{IEEE}{Institute of Electrical and Electronics Engineers\acroextra{, an organization that develops and publishes standards for electrical and computing technologies.}}
    \acro{JIT}{Just in Time\acroextra{, a method where code is translated from an intermediate representation into native machine code during runtime, immediately before execution, to improve performance.}}
    \acro{kTLS}{Kernel Transport Layer Security\acroextra{, a Linux kernel feature that offloads the encryption and decryption of TLS records from userspace applications to the kernel, aiming to improve performance by reducing data copies and enabling hardware acceleration.}}
    \acro{MITM}{Man-in-the-Middle\acroextra{, when an adversary positions itself between two communicating parties to intercept and manipulate their data, typically without their knowledge.}}
    \acro{NIC}{Network Interface Card\acroextra{, a hardware component that connects a computer to a computer network, allowing it to send and receive data.}}
    \acro{OC}{Ordinary Clock\acroextra{, a device with a single PTP port that can either be a source of time (master) or a receiver of time (slave).}}
    \acro{PAL}{Platform Abstraction Layer\acroextra{, a software layer in MsQuic, separated from the core QUIC logic, which holds the abstractions for TLS, UDP, and the OS.}}
    \acro{PHC}{PTP Hardware Clock\acroextra{, a highly accurate clock integrated directly into network interface cards to provide the precise timestamping of PTP packets. These clocks are necessary for the sub-microsecond resolution present in PTP.}}
    \acro{P2P}{Peer to Peer}
    \acro{PTP}{Precision Time Protocol\acroextra{, an IEEE standard that enables nanosecond-level clock synchronization across computer networks.}}
    \acro{QIR}{QUIC Interop Runner\acroextra{, an automated test framework that runs various test cases between different QUIC client and server implementations to assess and ensure their interoperability.}}
    \acro{RISC}{Reduced Instruction Set Computer\acroextra{, an instruction set architecture that prioritizes simpler, fixed-length instructions for faster execution and simpler processor design.}}
    \acro{RPS}{Requests per Second\acroextra{, a metric showing the number of requests a server can handle within a second.}}
    \acro{RSS}{Receive Side Scaling\acroextra{, a network driver feature that distributes the processing of incoming network packets across multiple CPU cores to improve network throughput and reduce CPU bottlenecks.}}
    \acro{TAI}{International Atomic Time\acroextra{, an extremely precise atomic timescale based on the weighted average of the readings of atomic clocks worldwide.}}
    \acro{TC}{Transparent Clock\acroextra{, a device that forwards PTP messages, and compensates for internal latency by adding its own processing time to the packet's correction field.}}
    \acro{TCP}{Transmission Control Protocol\acroextra{, an internet protocol that provides reliable, ordered, and error-checked delivery of data streams between applications over an IP network.}}
    \acro{TLS}{Transport Layer Security\acroextra{, a cryptographic protocol that provides end-to-end security for data transmitted over a network, ensuring privacy, integrity, and authenticity between communicating applications. It is most notably used to secure web traffic via HTTPS.}}
    \acro{TSN}{Time Sensitive Networking\acroextra{, a set of standards that provide deterministic messaging and guaranteed delivery for time-sensitive data over Ethernet networks.}}
    \acro{UDP}{User Datagram Protocol\acroextra{, a lightweight, connectionless protocol that QUIC uses as its layer 4 transport.}}
    \acro{UTC}{Coordinated Universal Time\acroextra{, the world's primary time standard, based on International Atomic Time (TAI) but adjusted by leap seconds to account for Earth's irregular rotation.}}
    \acro{XDP}{EXpress Data Path\acroextra{, a programmable hook within the Linux kernel allowing for early packet processing before the network stack.}}
    \acro{XSK}{XDP Socket\acroextra{, a Linux kernel socket and part of the AF\_XDP address family, which allows user-space applications to directly access raw network packets.}}
\end{acronym}
